1. Introduction to Rizviz ERP

Rizviz ERP is a comprehensive Enterprise Resource Planning system developed exclusively for Rizviz International Impex. It is designed to unify and streamline all core business processes across multiple companies and branches into a single, integrated platform.

This Administrator Manual is intended for users with the Admin role who manage the full Rizviz ERP environment — including HR, payroll, assets, projects, recruitment, interviews, leads, reports, and security audit.

Key Features

  • Multi-Company / Multi-Branch architecture
  • Role-based access control for secure, permission-driven usage
  • Centralized employee and HR management with live UAT database
  • Real-time payroll and salary processing with payslip generation
  • Asset inventory tracking — register, assign, and return
  • Project resource management and team allocations
  • Interview data synced from Interview Software.xlsx with change tracking
  • Leads pipeline derived from interviews or added manually
  • Corporate Reports Center — PDF and Excel export
  • Security Audit Registry — login and payroll action logging

5. Excel Sync — Interview Data Synchronization

All interview data in the system is sourced from an Excel spreadsheet. The platform supports two methods for syncing data: Manual Upload (via the Upload Excel button) and Automatic Watcher (file system monitoring in local development).

Upload Excel — How It Works

  1. Click the Upload Excel button (green button in the header bar or the toolbar).
  2. Select or drag your Excel file (.xlsx or .csv) into the upload area.
  3. The system validates the file for required columns: SR.NO and IntervieweeName.
  4. If validation passes, the data is parsed and compared with the existing database records.
  5. A Sync Summary modal appears showing: new rows added, changed rows updated, unchanged rows, and any failed rows.
  6. The interview table automatically refreshes with the latest data.

Refresh — Local File Sync

  1. Open Interview Software.xlsx on your local machine.
  2. Make changes — edit dates, names, statuses, or add new rows.
  3. Save the file with Ctrl+S.
  4. In the Interviews module, click the Refresh button.
  5. The system reads the updated Excel file, compares it with the database, and syncs changes.
  6. Review the sync summary modal for details on what changed.
Important: Rows are matched by the SR.NO column. Do not change the SR number of existing records unless you intend to create a new entry. Changing SR numbers will cause duplicate records.

Sync Summary — What Gets Compared

FieldDescription
New RowsRecords in Excel that don't exist in the database (matched by SR.NO)
Changed RowsRecords where one or more fields differ between Excel and database
Unchanged RowsRecords that are identical in both Excel and database
Failed RowsRecords that couldn't be synced due to validation errors or missing data
Deleted RowsRecords present in database but missing from the Excel file

Excel File Requirements

RequirementDetails
File Format.xlsx (recommended) or .csv
Required ColumnsSR.NO (sequence ordering) and IntervieweeName (candidate name)
Column MappingThe system auto-maps columns by header name. Additional columns (Invoice To, Interview Date, Company, Status, etc.) are mapped automatically if present.
Max File SizeUp to 10 MB recommended for optimal performance
Note: After every sync, the system stores the uploaded file as last_uploaded_excel.xlsx on the server. This ensures continuity even if the original file is moved or renamed.
